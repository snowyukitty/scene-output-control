What It Does

Scene Output Control has two main jobs:

Feature 01 Per-scene output presets

Apply resolution, FPS, recording, and monitoring-device settings when a scene becomes active.

 Feature 02 Personal monitoring mute

Stop hearing OBS-monitored sources without removing them from the recording mix.

Presets are stored in the scene source's private_settings, so they are saved with the scene collection and copied when a scene is duplicated.

Scene presets apply when entering a scene

The plugin does not automatically restore values from a previous scene. If Scene B does not override FPS, the current FPS remains whatever it already was. To make a scene use a value, explicitly enable and set that override for the scene.

Close OBS before replacing the DLL. On Windows, install the plugin files here:

One-time setup

Mute for Me, Keep Recording

After this one-time routing setup, Mute to me is a one-click control. The safe path is for OBS to capture the application, send it to the recording mix, and separately monitor it to your headphones.

  1. Remove direct playback from your headphones. In Windows Settings → System → Sound → Volume mixer, route the application to another output that you do not listen to, such as a monitor output or a virtual audio cable.
  2. Disable duplicate desktop capture. In OBS Settings → Audio → Global Audio Devices, set Desktop Audio to Disabled when the application source already captures its own audio.
  3. Choose your headphones explicitly. In OBS Settings → Audio → Advanced, set Monitoring Device to the headphones you actually use instead of Default.
  4. Send the source to both branches. Enable audio capture on the application/window/game source. In Advanced Audio Properties, choose Monitor and Output and select a recorded track.
Which audio track should I select?

No special track number is required. Track 1 is the simplest default. The source's checked track in Advanced Audio Properties must also be enabled under Settings → Output → Recording. If those choices do not match, the recording will not contain that source.

Verify the result

  • With Hear active, you hear the application once, without an echo.
  • With Mute to me active, you hear nothing from that source.
  • The OBS audio meter keeps moving and a short test recording still contains the audio.
Why can this not be completely automatic?

The plugin can configure OBS-owned settings, but Windows application routing is outside the OBS audio graph. It cannot safely guess which physical device you are listening to or silently install a virtual audio driver. A future setup checker can diagnose track, monitoring, and duplicate Desktop Audio settings; Windows routing will still require one explicit choice from you.

The resize feature

Per-Scene Resolution and FPS

This is the original resize feature: the plugin changes OBS's Base (canvas) resolution, Output (scaled) resolution, and FPS when you enter a scene.

It resizes OBS output settings, not individual sources

It does not automatically fit, crop, or stretch scene items. Source layout and transforms remain OBS scene controls.

Set it up

  1. Open Docks → Scene Output Control.
  2. Choose the target scene under Editing scene.
  3. Enable Enable per-scene overrides for this scene.
  4. Check Base resolution, Output resolution, and/or FPS, then enter the values for this scene.
  5. Use Apply now, or switch away and back to apply the preset automatically.
SettingMeaning
Base (canvas) resolutionThe OBS composition canvas size.
Output (scaled) resolutionThe recorded/scaled frame size.
FPS (integer)The integer frame rate written into the active OBS video configuration.
OBS cannot change video settings while outputs are active

Resolution and FPS changes require the OBS video pipeline to be idle. If recording, streaming, or virtual camera output is active, OBS rejects the change. The optional restart-recording setting can stop recording, apply video changes, and start a new recording when no stream or virtual camera output is active.

Recording

Recording settings are staged for the next recording. They do not rewrite an already-running recording output.

Actions

  • Copy from current OBS settings fills the form with current OBS values without automatically enabling any overrides.
  • Apply now saves and applies immediately when the edited scene is also the current program scene.

Monitoring Vs Recording

OBS audio has two separate paths. The output mix goes to recording and streaming; the monitoring path is playback for you to hear. Scene Output Control only changes the monitoring path for monitoring features.

To hear it and record it, use Monitor and Output

Open OBS Advanced Audio Properties, set the source's Audio Monitoring to Monitor and Output, and assign it to a recorded track. Monitor Only can also be silenced, but OBS intentionally excludes that source from recording and streaming. Audio played directly by the operating system does not pass through this control.

Per-Scene Monitoring Device

Enable Monitoring device and choose where OBS should play monitored audio when the scene becomes active. This can change while recording because it does not touch the encoder path.

Mute To Me

The top button globally stops you from hearing OBS-monitored audio. Press it again to hear monitoring again.

  • For Monitor and Output, the plugin temporarily disables only the monitoring branch. The source remains in the OBS output/encoder mix.
  • For Monitor Only, the plugin temporarily mutes the source because OBS already excludes it from recording and streaming.
  • If no source currently uses audio monitoring, the button shows Armed and automatically suppresses a source when monitoring starts.
  • If a source cannot be changed or restored safely, the button shows Mute error instead of claiming that monitoring is silent.
  • The plugin stores each source's exact prior state in private scene-collection data before changing it, restores it when disabled or unloaded, and retries recovery after an interrupted OBS run.
  • Only one OBS process owns Windows recovery state. Later OBS instances show this control as unavailable.
  • OBS recording tracks, source volume, and encoder settings are not changed.
How is the original monitoring setup protected?

OBS persists each source's monitoring type when saving a scene collection. The plugin therefore writes recovery metadata into the source's private settings before changing monitoring and immediately saves both together. Unmute, unload, and next-start recovery restore the exact prior state.

Why not mute the OBS Windows playback session?

Application, window, and game audio capture can share an OBS-owned Windows audio session with monitoring. Muting that session can also silence the captured signal and the recording. This control stays at the per-source monitoring boundary instead.

Limits

  • Resolution and FPS changes require OBS outputs to be idle, unless the plugin restarts recording.
  • Recording bitrate override requires Advanced output mode.
  • Mute to me only controls audio heard through OBS monitoring.
  • Only the first active OBS instance can use Windows Mute to me; later instances must restart after the owner exits.
  • Recording folder, format, tracks, and bitrate apply to the next recording, not the current output.

Example Workflows

Game scenes at 1080p60, talk scenes at 1080p30

Enable output resolution and FPS overrides on each scene. Switch to the scene before starting recording, or allow the plugin to restart recording if that workflow is acceptable.

Different folders or formats per scene

Enable recording folder and format overrides for each scene. The next recording uses the active scene's staged values.

Long recordings where you stop listening mid-session

Set sources to Monitor and Output, then use Mute to me. The recording continues unchanged.

FAQ

I clicked Mute to me but still hear sound.

If the sound becomes quieter but does not disappear, you are probably hearing two paths: OBS monitoring plus direct Windows playback. Follow Quick Audio Setup so the application does not play directly to your headphones, disable duplicate Desktop Audio capture, and use Monitor and Output for the source.

Does audio need to use a specific track?

No. Track 1 is the simplest default, but any track from 1 through 6 works when the source is assigned to it and the same track is enabled for recording output.

Resolution did not change when I switched scenes.

First confirm that the scene preset and the individual video override are enabled. If they are, an OBS output is probably active: OBS does not allow video pipeline changes while recording, streaming, replay buffer, or virtual camera output is running.

How do I leave compact dock mode?

Click Show resize / output settings. You can also right-click the compact Mute / Hear button and choose Show full settings.

Do presets follow duplicated scenes?

Yes. Presets live in source private settings, which OBS copies during scene duplication and serializes with the scene collection.
